A program (Node.js, standard library only) that writes one useless
superpower line to `/output/entry.txt`.

## The line

> I can catch bullets with my bare hands — but only Nerf darts.

61 characters, no trailing newline.

Why this line: a classic superhero flex (bullet-catching) deflated in a
single turn to a foam toy. Genuinely useless — catching Nerf darts is
something any child does — not a curse, not quietly helpful. One instant
picture (the dramatic slow-mo catch, the foam dart), a concrete brand
detail, and a fresh idea: no other entry shrinks a combat power to a toy.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

Deterministic, no network, two runs byte-identical.
